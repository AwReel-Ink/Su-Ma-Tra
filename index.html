🔄 Synchronisation entre mobiles

📱 Mobile A
QR Code
📱 Mobile B

Cette fonction permet de fusionner les saisies effectuées sur plusieurs téléphones ou tablettes, afin que chaque appareil dispose de toutes les données à jour.

1 L'appareil A génère un QR code
2 L'appareil B le scanne avec sa caméra
3 Un second QR confirme la connexion directe
4 Les données se fusionnent automatiquement
💡
Fonctionne sans internet — un appareil active son point d'accès mobile (hotspot), l'autre s'y connecte, puis la synchronisation se lance. Idéal sur chantier, en atelier, partout sans réseau.

Pour récupérer les données sur un PC, utilisez l'export Excel ou JSON disponibles ci-dessus, et partagez le par e-mail.
